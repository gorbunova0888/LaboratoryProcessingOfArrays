# Лабораторная работа №4: Обработка массивов

## Автор
Горбунова Настя

## Вариант
Вариант 5

## Описание
Программа обрабатывает двумерный массив (матрицу). 
В заданной матрице F все отрицательные элементы заменяются на нули. 
Исходная и полученная матрицы выводятся на экран в общепринятом (табличном) виде.

## Входные данные
- Количество строк матрицы (от 1 до 20).
- Количество столбцов матрицы (от 1 до 20).
- Элементы матрицы (вещественные числа), вводимые построчно через пробел.

## Выходные данные
- Исходная матрица.
- Матрица, в которой отрицательные элементы заменены на нули.
